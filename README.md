
# 🏦 Bank Management System

A simple **console-based Bank Management System** developed using **Python**.

## 📌 Features

* 💰 Check account balance
* ➕ Deposit money
* ➖ Withdraw money
* ❌ Exit the application
* ⚠️ Validates insufficient balance
* ⚠️ Prevents invalid deposit and withdrawal amounts

## 🛠️ Technologies Used

* Python
* Functions
* Conditional Statements
* Loops
* User Input Handling
* Global Variables

The application provides the following options:

```text
Enter '1' for Balance Check
Enter '2' for Add Money
Enter '3' for Withdrawal Money
Enter '4' for Quit
```

## 💡 How It Works

The application starts with a balance of `0.0`. Users can select an operation from the menu. The program continuously runs until the user selects the Quit option.

The `deposit()` function adds a valid amount to the balance, while the `withdrawal()` function checks the available balance before completing a withdrawal.
